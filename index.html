02 / 真正影响使用的细节

给老人用，更该比较这四件事

01

操作熟悉，能省下很多学习成本

老人原来用红米，继续选择红米通常更容易衔接。但不同系统版本也有变化，到手后仍应整理桌面和常用入口。

02

字能否看清，比屏幕尺寸数字更直接

先调大系统字体、图标和微信字体，再让老人试读。6.59英寸也能放大字体；如果仍觉得内容拥挤，再选6.83英寸。

03

听筒和外放，要实际听一下

分别试电话听筒、免提、来电铃声和微信语音。扬声器参数无法直接证明老人听得清，音量大也不等于人声清楚。

04

先试握持，再决定是否要更大电池

大电池通常伴随更大的机身。戴壳握持、举起来拍照，感受是否累手；续航还受亮度、信号和使用方式影响。

03 / 内存怎么选

照片和微信多，优先留足空间

优先推荐

12GB + 512GB

照片、视频、微信聊天都会占空间。准备使用几年，更适合优先选这一档。

预算折中

12GB + 256GB

日常使用够用，适合愿意定期清理视频、把照片备份出去的情况。

控制预算

8GB + 256GB

基本日常也能用。如果与12GB版本差价不大，优先选12GB。

12GB是运行内存，512GB是存储容量。对这类使用需求，16GB运行内存的优先级较低，可以先把预算放在512GB存储上。

04 / 下单与设置清单

买对版本，
也要帮老人设置好。

截图中有多条商品要求“当面签收激活”。提前弄清规则，收到手机后再逐项检查。

  1. 选好规格，再比较实付价格

    核对8GB / 12GB / 16GB运行内存、256GB / 512GB存储，以及优惠是否有条件。

  2. 确认激活后的退换规则

    提前问清现场拆封、联网激活后，能否七天无理由退货，质量问题如何处理。

  3. 核对店铺、发票与全国联保

    “官方正品”等商品标题文字，不能单独证明是官方直营店。

  4. 试屏幕、声音和戴壳后的握持

    让老人实际读文字、听电话和微信语音，举起手机拍一张照片。

  5. 调大字体，保留熟悉的操作方式

    系统、图标、微信字体分别调整；不习惯手势时，可设置底部三个导航键。

  6. 迁移资料，整理桌面

    确认联系人、照片、微信聊天记录和账号登录完整后，再处理旧手机。关闭不需要的推荐和通知，设置紧急联系人。

两组名字别混淆：iQOO Z11 与 Z11 Turbo 是不同机型；一加 Turbo 6 与 Turbo 6V 也是不同机型。同一款手机出现在不同店铺里，价格变化不一定代表硬件版本更好。
